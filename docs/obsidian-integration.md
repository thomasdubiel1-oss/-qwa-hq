# Obsidian Integration

Obsidian is QWA's durable knowledge layer, not the executable source of truth.

Vault: 00-Inbox, 01-Architecture, 02-Product, 03-Agents, 04-Engineering, 05-Research, 06-Competitive-Intelligence, 07-Operations, 08-Decisions, 09-Runbooks, 10-Postmortems, 99-Archive.

Hermes accesses Obsidian through scoped MCP with path allowlists and audit logging. Never store credentials, tokens, customer secrets or raw production data in the vault.
